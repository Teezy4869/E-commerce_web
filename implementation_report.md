## 4. Important Implementation Decisions

### Voice
Speech recognition is simulated. `VoiceInput` sends the supplied transcript to `SpeechService`, which validates and returns it unchanged.

### Image
The baseline uses deterministic artificial three-dimensional embeddings. `ImageService` maps the supplied sample query image paths to known vectors. Unknown paths are rejected instead of generating random embeddings, making the demonstration deterministic and easier to explain.

### Retrieval and Ranking
`SearchService` only retrieves candidates. `RankingService` separately orders candidates by the retrieval score.

### Layer separation
Presentation modules do not import Data modules. Application modules do not import Presentation modules. Data modules remain independent of both upper layers.

## 5. Dataset

- 12 products
- 3 orders
- 12 product sample JPEGs
- 3 query sample JPEGs
- 3-dimensional artificial product embeddings

The assignment requires at least 10 products, so the 12-product dataset exceeds the minimum without making the prototype unnecessarily large.

## 9. Limitations

1. Speech-to-text remains simulated.
2. Image embeddings are artificial, not generated by a real image model.
3. Text retrieval is keyword matching rather than semantic retrieval.
4. Data is loaded from JSON into memory and is not persisted through a production database.
5. The prototype is console-based.
6. Ranking is simple score-based sorting.

These limitations are intentional baseline choices and align with the assignment's prototype-first scope.
