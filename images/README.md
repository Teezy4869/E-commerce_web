# Image Storage

The baseline includes small sample JPEGs for demonstration. They are illustrative images only. The prototype does not extract features from their pixels; `ImageService` maps the three query sample paths to deterministic artificial embeddings, as permitted by the assignment. Product image files are stored here to keep the dataset image paths valid.

Supported query samples:
- `query_shoes.jpg`
- `query_bag.jpg`
- `query_watch.jpg`
